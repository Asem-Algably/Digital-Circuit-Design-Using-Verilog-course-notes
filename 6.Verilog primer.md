- we use Verilog to write code that describes our circuit thus it’s called a hardware description language (HDL) 
- pay attention that it’s a description language not a programming language
- Verilog designs fall under two categories :-
	- structural representation
	- behavioral representation

- **structural representation**: is when we define a circuit by describing it’s logic blocks like defining the AND, OR, NOT logic blocks and their connection

- **behavioral representation**: is when we define a circuit by describing how it works like saying when a particular signal is on make this output a certain value, when it’s off make it another one and so on
