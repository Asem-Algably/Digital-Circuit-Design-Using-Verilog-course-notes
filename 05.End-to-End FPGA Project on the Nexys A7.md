### How to start a project on an FPGA
- first you create a new project (make sure that there is no spaces either in the project name or in the project path)
- specify the FPGA you are working on
- add a source from the plus sign in the sources window
- define the module of the source you just created
---
### How to write Verilog modules
```verilog
// start by defining your inputs and outputs in the module header
module buff(  
	// you define your inputs by starting with the word input and you can     put them next to each other if they are the same size
    input I,B,C,
    input A, // if they aren't the same size put them on seperate lines
    output O // and you define outputs the same way you define inputs
    );
    
    // and then you can descripe your circuit using a c similar syntax
    assign O = I;  // notice that you have to end each line with ;
endmodule
```

once you have many inputs and outputs defining each one of them can get cumbersome so you can use buses
```verilog
module buff(
    input [15:0] I,
    output [15:0] O
    );
    
    assign O = I;
endmodule

```
buses are similar to C arrays (**but they aren’t**) in the sense that they allow you to group and define multiple variables at once, here the `I` is a 16 bit input bus and `O` is a 16 bit output bus

---
after defining your module you can check the circuit using `open elaborated desing` in the flow navigator


> [!NOTE] 
> after defining your Verilog modules you need to map them to your FPGA and you can do that through adding a constraint
> you can use constraint templates provided by your board manufacturer

---
### How to add constraints
adding constraints from the manufacturer template is done through uncommenting the component you want to use and then hooking it to your defined signal by placing it’s variable in `get_ports {}` 
```tcl
##Switches
set_property -dict { PACKAGE_PIN J15   IOSTANDARD LVCMOS33 } [get_ports { I }]; #IO_L24N_T3_RS0_15 Sch=sw[0]

#set_property -dict { PACKAGE_PIN L16   IOSTANDARD LVCMOS33 } [get_ports { SW[1] }]; #IO_L3N_T0_DQS_EMCCLK_14 Sch=sw[1]

#set_property -dict { PACKAGE_PIN M13   IOSTANDARD LVCMOS33 } [get_ports { SW[2] }]; #IO_L6N_T0_D08_VREF_14 Sch=sw[2]
.
.
.
.
## LEDs

set_property -dict { PACKAGE_PIN H17   IOSTANDARD LVCMOS33 } [get_ports { O }]; #IO_L18P_T2_A24_15 Sch=led[0]

#set_property -dict { PACKAGE_PIN K15   IOSTANDARD LVCMOS33 } [get_ports { LED[1] }]; #IO_L24P_T3_RS1_15 Sch=led[1]

#set_property -dict { PACKAGE_PIN J13   IOSTANDARD LVCMOS33 } [get_ports { LED[2] }]; #IO_L17N_T2_A25_15 Sch=led[2]
```

### uploading code to your FPGA
after that we are ready to generate our bitstream (through `Generate bitstream`) and upload it to our FPGA 
to upload you bitstream to you board you need to click to the `open hardware manager` to connect to your FPGA power it on and connect it, then in the `HARDWARE MANAGER` window click open target then auto connect
